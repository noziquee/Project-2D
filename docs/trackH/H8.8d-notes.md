# H8.8d: skills on the touch buttons, hotbar hidden on touch (October 28, 2026)

Status: written, **not run** (no Godot in the build environment). Expect part `h8_skillface`, H8-225 to H8-231, to pass; run it with `--only=h8_skillface`, then the full suite.

## What changed
- On touch the three skill buttons (`Button_skill_1` to `_3`) now show the skill: icon, cooldown sweep and seconds, cast ring, resource cost, a dimmed icon and red cost when it cannot be afforded, and a short green ring when it is ready again. An empty slot keeps the number caption.
- The hotbar (`HUD/PlayerSkillBar`) is hidden while the active device is touch, and comes back on keyboard/mouse and controller. Nothing about PC or console changed.

## Files
| File | Change |
|---|---|
| `UI/Touch/TouchSkillFace.gd` (new) | Draws the skill on a skill button. Display only; ignores touches. Mirrors `SkillSlot` (SkillComponent2D stays the authority). |
| `UI/Touch/MobileControls.gd` | `_register_button` adds a `SkillFace` child to each skill button (scene or code layout), binds it to the player's SkillComponent2D; `get_skill_face(action)`. |
| `UI/HUD/SkillBar.gd` | `visible = device != TOUCH` in `_on_device_changed`. Slot binding and labels are untouched (H7-70 still holds). |
| `tests/smoke_checks.gd` | New part `h8_skillface`, H8-225 to H8-231. |

No scene edits are needed: the face is created at runtime. `GroundCircle`, aim, drag and cast behavior of the buttons are unchanged.

## Look at on a phone
1. Icons sit in the button circle (square at 1.38 x radius); check they are not cut at the edge.
2. Cooldown text size (0.62 x radius) and cost text (0.3 x radius) on a small phone.
3. The hotbar is gone on touch; `MobileControls.debug_force_visible` on a desktop does not hide it (only the device does).
