## Rules pinned by the checks
- Eligible: in the `damageable` group, alive, valid, not the caster, not on the caster's own non-empty team, inside the shape (the shape's margin is `target_margin`, 8 px).
- Scenery and unregistered crates are never picked: only the group counts.
- Choice is made at `begin_action()` + `resolve()` and kept for that action; replaced only if the target dies, is freed or leaves range (`shape.max_range + margin`). A freed target raises no error.
- Next action: re-chosen, but the previous target gets +0.15 so a near tie does not flip.
- Direction = origin to target. No target: intended aim, else last valid aim, else last facing, else right. A plain tap (no intended aim) searches along the last valid aim. No shape = fallback only.
- Manual aim: used as given, no search, no stored target.

## Decisions made here (tell me if you disagree)
1. **Axis for the search** is the intended aim, else the last valid aim, else the facing. So a touch tap with no drag looks where the character was last aiming or facing.
2. **Range check for stickiness** uses distance only, not direction, so an enemy that circles you stays targeted for the action.
3. **No line-of-sight rule** (walls do not block assist). Easy to add later if arena walls make it feel wrong.
