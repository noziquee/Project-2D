# H4.5c: the 5,300-line core is ten runnable parts

Written Oct 27, 2026. Not run: no Godot in the sandbox. Expected `SUMMARY passes=1190 failures=0` (same as H4.5a: no check was added or changed).

## Why it was safe to cut

The worry was local variables shared between sections (A to P8). I scanned all 72 sections for a variable declared in one section and used in a later one.

- `main`, `p`, `e` (declared in A, re-assigned at the start of every later section), `ai` and `ke` (declared once, re-assigned later): each part that assigns one of these without declaring it now declares it on its first line (`var main: Node`, `var p`, `var e`, `var ai: EnemyAIController2D`, `var ke: Character2D`, same types as the original declarations).
- `ii_light`, `ii_sword`, `ii_ids_before` (II to JJ) and `e`/`main`/`p` (A to B): those sections are in the same part.
- `dealt` looked shared; it is a lambda parameter in the later sections, not a shared variable.
- Afterwards the same scan over the new functions finds no name used in one part and declared in another.
