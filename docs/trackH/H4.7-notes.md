# H4.7: the suite runs on every change

Written Oct 27, 2026. Not run: a workflow only runs on GitHub, and there is no Godot in my sandbox. No game code and no check changed, so the expected total stays `SUMMARY passes=1192 failures=0`.

## What it does

`.github/workflows/checks.yml` runs on every push, every pull request and by hand (`workflow_dispatch`):

1. Downloads Godot `GODOT_VERSION` (4.7.2, set once at the top of the file) from `godotengine/godot-builds` and caches it. I confirmed that the 4.7.2 Linux x86_64 release file exists at that address.
2. Warns (a yellow notice, not a failure) when `tests/expected_errors.txt` is not in the repository, because the error gate (H4.4) is then not armed.
3. Runs `bash tools/run_checks.sh` (import, then the suite). The script exits 1 when a check fails, when the suite never prints its SUMMARY line, or when Godot exits non-zero. Unexpected errors fail through check H4-25.
4. Writes the SUMMARY, any `CHECK FAIL` or `UNEXPECTED ERROR` lines into the run's summary page, and attaches the whole log as the `smoke-log` artifact.

A newer push to the same branch cancels a run still going. The job stops after 30 minutes.

## Needs from you

- Commit and push `.github/`, `tests/`, `tools/` and `docs/` (none of `tests/`, `tools/` or `.github/` is tracked yet in the archive's git history).
- Commit `tests/expected_errors.txt` after `tools/run_checks.sh --record-errors`, or the gate stays off.
- GitHub Actions must be enabled for the repository (the default for a personal repository).

## Limits

- The first CI run will be red if the suite is red; the suite has not been run since H2.1. That is the workflow working, not failing.
- Headless Godot on a GitHub runner is not the same machine as yours: a timing-sensitive check (the bow cycle, dash distances) could pass locally and fail there, or the other way round. If so, it shows up as a difference between the two, and the run log tells which check.
- Not added on purpose: `--twice` in CI (doubles the run time; use it locally), and a local pre-commit hook (a full run is too slow to run on every commit).
