# H9.5 — clip aimed areas to each action's own range

Written October 28, 2026. Implemented in source; Godot import, smoke suite, and editor play-test are pending because this environment has no Godot executable.

## Changes

- `AimIndicator2D` clips each non-placed aim outline against a circle using `Geometry2D.intersect_polygons`. `player.gd` passes the active definition's `get_reach()` (heavy attack or skill), rather than the light-attack radius or a global constant; the shape's `max_range` is the fallback. No shared radius is introduced.
- Line/arrow aim areas are clipped, including the arrow head, so the side corners and decorative head cannot visibly extend beyond the action's reach. Fan and self-circle shapes use the same path for consistent geometry.
- Ground-circle placement remains separate: its area stays centred at the selected placement point, while its caster-centred cast-range ring remains drawn as before.
- The light-attack range circle remains the responsibility of `AssistIndicator2D` and is not hidden by this change. Clipping is presentation-only; targeting, hitboxes, reach, and damage rules are unchanged.
- Added geometry checks H9-55 through H9-59 for a line, very wide line, fan, zero range, and self-circle.
