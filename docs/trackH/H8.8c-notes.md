# H8.8c: touch layout moved to a scene (October 28, 2026)

Status: built. Checked headless on Godot 4.7 in a stripped-down project (7 checks, H8-218 to H8-224, all pass: the scene and the code layouts have the same
rectangles, captions and wiring). **Not run in your full project**, and **`HUD/MobileControls` in your Main scene still has to be swapped** (below).

## Edit the layout
Open `UI/Touch/MobileControls.tscn`. It holds:
- `MoveStick` (a ColorRect placeholder; at runtime it is replaced by a real `VirtualStick` with the same anchors and offsets, so move and resize it freely).
- `RightCluster` (anchored to the bottom-right corner), holding `Button_attack_light`, `Button_dash`, `Button_weapon_next`, `Button_skill_1` to `Button_skill_3`.
Move or scale any of them in the 2D view or with the Inspector (offsets). The buttons draw in the editor (`TouchActionButton` is now `@tool`). Per-button
tuning is in the Inspector too: `caption`, `drag_threshold`, `aim_dead_zone`, `aim_reach`.

## Use it in the game
In `Main.tscn`: delete the `HUD/MobileControls` node (note its `debug_force_visible` setting), drag `MobileControls.tscn` into `HUD` and make sure the node is named
`MobileControls`. Until you do, the game keeps building the same layout in code, so nothing breaks.

## Rules
- Buttons are found by their `action`, not by node name or order. Keep `action` set: `attack_light`, `dash`, `weapon_next`, `skill_1` to `skill_3`.
- What a button *does* is still wired in code (`MobileControls._register_button`): the attack button drags to aim, skill buttons cast on the lift. The scene cannot change that.
- Keep the cluster clear of the skill bar (H7-67 checks this at 1280 wide).
- The size and ARC exports on `MobileControls` now only apply to a node with no children (the code fallback).

## Files
`UI/Touch/MobileControls.tscn` (new), `MobileControls.gd` (adopts a scene layout, else builds it; one `_register_button`), `TouchActionButton.gd` (`@tool`, ignores
editor input), `tests/h8_aim_checks.gd` and `tests/smoke_checks.gd` (new part `h8_layout`, H8-218 to H8-224).
