# H7.4: controller bindings and right-stick aim (October 28, 2026)

Status: written, not yet run. Needs `tools/run_checks.sh` (expected `SUMMARY passes=1207 failures=0`) and a play on a real controller.

## What changed

- `project.godot` (input map): joypad events added to every combat action, and four new actions `aim_left`, `aim_right`, `aim_up`, `aim_down` on the right stick (dead zone 0.25). `attack_light` now has dead zone 0.5 so a light touch of the trigger does not attack. Keyboard and mouse events are untouched.
- `player.gd`: `_get_aim_direction()` reads the aim stick first (`Input.get_vector` applies the dead zones). Once the stick has aimed, its last direction is kept when it is released; any `InputEventMouseMotion` or `InputEventMouseButton` (new `_input`) hands the aim back to the mouse. With no controller connected nothing changes.
- `tests/smoke_checks.gd`: new part `h7_input` (`run_h7_input_checks`, checks H7-1 to H7-9). Three older checks assumed one binding per action and were widened: U2 (`attack_heavy` has no keyboard or mouse binding), YY1 (`weapon_next` has exactly one key), GGG3 (`skill_1` to `skill_3` have one key each).

## Controller map

| Action | Binding |
|---|---|
| `move_left/right/up/down` | Left stick axes 0 and 1, D-pad buttons 13, 14, 11, 12 |
| `aim_left/right/up/down` | Right stick axes 2 and 3 |
| `attack_light` | Right trigger (axis 5) |
| `attack_heavy` | RB (button 10) |
| `dash` | A (button 0) |
| `weapon_next` | LB (button 9) |
| `skill_1`, `skill_2`, `skill_3` | X (2), Y (3), B (1) |

The guide's table is an example, not a rule; change any of these in Project Settings > Input Map. H7-2 fails if two actions end up on the same button or stick direction.

## Checks

H7-1 every combat and aim action has a controller binding. H7-2 no controller input is bound to two actions. H7-3 keyboard bindings and left mouse for `attack_light` are unchanged. H7-4 no stick: aim is the direction to the mouse. H7-5 a stick below the dead zone does nothing. H7-6 a pushed stick sets the aim. H7-7 releasing it keeps the last direction. H7-8 moving the mouse hands the aim back. H7-9 a dead player ignores the stick.

## To try by hand

Move with the left stick and aim the bow with the right stick; hold RT for a charged shot; tap RB; use X, Y, B for skills; LB swaps weapons. Then move the mouse and check the aim returns to it.
