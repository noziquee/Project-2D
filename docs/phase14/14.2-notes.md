# 14.2 - First passive as the test: Rising Strikes

Written October 25, 2026 without running Godot. Checks PAS1 to PAS21 are counted in `14.1-notes.md` (expected `SUMMARY passes=908 failures=0`).

## The passive
`Characters/Components/Passives/RisingStrikesPassiveDefinition.tres`: three qualifying swings (4 s window between swings) grant `rising_strikes` (`Characters/Components/Status/RisingStrikesStatusDefinition.tres`: 8 s, outgoing damage x1.5). The next attack uses it up. It uses the 13.3.4 damage multiplier, so no resolver change was needed.

**It is not on any weapon.** Attaching it to the sword would raise the damage of every later test swing, so the shipped game plays as before. To try it: open `Data/Weapons/SwordWeaponDefinition.tres`, add `RisingStrikesPassiveDefinition.tres` to **Passives > Passive Skills**. Then every third landed swing gives the next swing x1.5 damage. Re-run the smoke test afterwards: tests that count sword damage over several swings will see the bonus, and any such failure is expected until those tests pin their own weapon.

## The checks
| Check | What it proves |
|---|---|
| PAS1 | The shipped passive and status load with the stated values and validate. |
| PAS2, PAS3 | Invalid passives are reported; a weapon reports empty, duplicate and invalid passives; `get_passive()`. |
| PAS4 | One count per swing that hits; a miss changes nothing. |
| PAS5 | A three-target swing counts once; the reward is granted when the swing closes. |
| PAS6 | The next attack uses it up, its hits do not count, counting restarts. |
| PAS7 | Combo chain: granted when the next link starts, used by that link only. |
| PAS8 | The counter window. |
| PAS9, PAS10 | Death resets the counter and removes a granted reward. |
| PAS11 | A non-consumed reward runs its duration; no counting while it runs. |
| PAS12, PAS13 | Replacing passives; invalid and duplicate ones are skipped. |
| PAS14 | A cancelled swing still uses the reward up. |
| PAS15 | The player is wired; shipped weapons have no passives. |
| PAS16 to PAS21 | On the real player with real swings: equip, count, earn, empowered damage (`round(damage x 1.5)`), back to normal, unequip. |

The real-swing checks (PAS17 to PAS20) take about 5 swings of game time. They put the goblin 28 px away with physics off, like check B.
