## New file
- `Characters/Components/Weapons/WeaponController2D.gd` (`class_name WeaponController2D`, a `Node`)
  - `initialize(context, attack_component)`: like the other components, it gets the shared context here, never in `_ready()`.
  - `validate_equip(weapon) -> Array[String]`: every reason the weapon would be refused, each naming the weapon. Empty = can equip. Changes nothing.
  - `can_equip(weapon) -> bool`.

## What validate_equip() checks
- controller initialized; the character has a `WeaponFacingPivot` (the goblin does not, so it cannot swap weapons);
- the character is not in a swing or a charge (`context.is_attacking`);
- the weapon's own data (`WeaponDefinition2D.validate()`);
- the clips: against the weapon's own scene when it has one (`validate_scene()`), otherwise against the weapon player the character has now;
- per attack, what `AttackComponent2D` would reject later: an `effect_scene` that cannot be instantiated, and a THRESHOLD release with `charge_threshold` of 0.

Duplicate messages are dropped.
