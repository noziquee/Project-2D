# Phase 9.6b – the return starts when the combo window closes with no press

Smoke test: expected `SUMMARY passes=343 failures=0` on Godot 4.7.2 (339 from 9.6a + 4 new checks, EE1–EE4), assuming 9.6a passes. Not run here: please run it and paste the SUMMARY line.

Code and tests only. No scene or `.tres` data changed.

## What changed
- `Characters/Components/Combat/AttackComponent2D.gd`
  - `combo_window_close` now does one more thing: if the swing is still in its weapon clip, it ends that clip there.
    - An attack with a `recovery_animation` starts it at once (`_in_recovery`).
    - An attack with no return clip finishes at once, and its weapon pose is reset to `RESET`.
  - A press inside the window never reaches this path, because a press chains first and the new swing starts with a fresh window.
  - Attacks with no window keys are unchanged: their return still starts when the weapon clip ends.
- `tests/smoke_checks.gd`
  - `weapon_cycle_seconds()` uses the close key as the end of the slash when the clip has a window close key. Without this the attack-rate checks (H-player) would expect a full-length slash and fail.
  - Section EE (EE1–EE4).

## Effect on the light attack
- The light swing now lasts to its close key (0.26 s), not the end of the clip (0.29 s), when no press came. That is about 0.03 s shorter, as decided.
- A press that lands in the window still chains as before.

## Things to check in play
1. Tap attack once: the return plays at about 0.26 s into the swing, with no visible jump.
2. Tap, then tap again in the window: the second swing starts at once, as before.
3. Play a three-link loop (after 9.6a is wired to a sequence): the return should only start after the last link.
4. If the return looks cut too sharply, move the `combo_window_close` key later in the `slash` clip (the rule holds for any close key).

## Not in this step
- Heavy charge (9.6c) and player wiring (9.6d).

## Superseded by 9.R (clip numbers)
The "0.26 s" close key and "0.29 s" clip length refer to the old `slash` clip. The current light clips (`sword_slash_1`, `sword_slash_2`) are 0.5 s long with the window closing at 0.417 s, so a swing with no press now returns at 0.417 s. The rule itself (the return starts at the close key) is unchanged.
