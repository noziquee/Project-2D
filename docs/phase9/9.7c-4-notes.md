## Editor steps (player.tscn)
1. Open the project once so Godot registers `WeaponController2D` (or run `godot --headless --import --path .`).
2. In the FileSystem dock, double-click `player.tscn`.
3. In the Scene dock, click the root node **Player** once.
4. Click the **Add Child Node** button (the + icon at the top of the Scene dock, or Ctrl+A).
5. Type `WeaponController2D` in the search box, select it, click **Create**. It must appear directly under **Player**, next to `AttackComponent2D` (not under another node). If it landed elsewhere, drag it onto **Player**. Leave its name as `WeaponController2D`.
6. Click the new **WeaponController2D** node. In the Inspector, find **Starting Weapon**.
7. In the FileSystem dock open `Data/Weapons/`, and drag `SwordWeaponDefinition.tres` into the **Starting Weapon** slot (or click the slot, choose **Quick Load**, pick it).
8. Leave **Player** > Inspector > Components > **Weapon Controller** empty: like the other components it is found by its child name.
9. Press **Ctrl+S** to save, then run the smoke test.
10. Run the game once and look at the Output panel: no new warnings or errors are expected.

## What changed in code
- `Characters/Core/Character2D.gd`: new optional `weapon_controller` export, resolved like the other components but **not** reported as missing (the goblin has none). After the attack component is initialized, the controller is initialized with the context and the attack component.
- `Characters/Components/Weapons/WeaponController2D.gd`: new `starting_weapon` export. When the controller initializes successfully, it equips it. The sword's scene is the mounted one, so nothing is swapped; the default attack and the `attacks` list are set to exactly what `player.tscn` already has (`player_light`, then `player_light2` and `player_heavy`). If the equip fails, the warnings name why and the character keeps its scene's attacks.
- `tests/smoke_checks.gd`: section NN appended. Nothing existing changed.
- `docs/phase9/PLAN.md`.
