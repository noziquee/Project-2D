# Phase 9.6a – looping combo sequences, repeat when unlinked, reset

Smoke test: expected `SUMMARY passes=339 failures=0` on Godot 4.7.2 (331 from 9.5b + 8 new checks, DD1a–DD5b), assuming 9.5b passes. Not run here: please run it and paste the SUMMARY line.

This step is code and tests only. No scene or `.tres` data changed, so the shipped player still chains light → light2 through `next_attack`.

## What changed
- `AttackDefinition2D.combo_sequence` (new, Combo group): an ordered loop that starts with the attack itself, e.g. `[A1, A2, A3]` plays A1 → A2 → A3 → A1.
- `AttackComponent2D`
  - A combo started from an attack with a sequence keeps that sequence and an index at runtime (`_combo_sequence`, `_combo_step`). Neither is stored in a resource.
  - A chain plays the next entry of the sequence, looping; then the explicit `next_attack` link; then the same attack again.
  - The combo ends, and its state is cleared, when a swing finishes, is cancelled or is interrupted, and the next swing starts a fresh combo.
  - `validate_combo_links()` now also reports a sequence that does not start with its own attack, and sequence entries that are not registered.

## Intentional changes to existing expectations
- **W4**: a link to itself is now valid and means "repeat", not "invalid". It is still never followed as an explicit link.
- **Y7**: an attack with no link no longer refuses a request inside its window; it repeats itself. This is decision 2 of the 9.6 plan.

## Rules to know
- Repeat applies to attacks with window keys only: attacks without window keys never chain, so nothing changes for them.
- A broken `next_attack` (not registered) now falls back to repeating the attack. It used to refuse the chain. It is still reported by validation.
- The sequence wins over `next_attack` while a combo is running.

## What the tests cover (DD1a–DD5b)
- A valid loop validates; an unregistered entry and a sequence that does not start with its own attack are reported.
- The loop plays 1 → 2 → 3 → 1 through the real chain path.
- An attack with no sequence and no link repeats.
- A finished combo and an interrupted combo each restart at the beginning of the sequence.

## Not in this step
- Return on window close (9.6b): the window still closes without ending the swing early.
- Heavy charge (9.6c) and player wiring (9.6d).
