# Phase 13.4 smoke follow-up fix v5

## EEE62 — transient area reference

The area test waits 25 physics frames before evaluating the full assertion. `AreaEffect2D` has a short `active_time` and can free itself during that wait, so the test must capture whether the area was valid at spawn time rather than evaluate its transient object reference after it has expired.

The check now caches `is_instance_valid(eee4_nova_area)` before the wait, uses that cached result for the spawn assertion, and includes it in the failure diagnostic. The actual behavior checks for centering, attack-derived radius, nearby-target damage, and caster safety remain in place.
