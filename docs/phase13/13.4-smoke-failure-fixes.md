# Phase 13.4 smoke-check follow-up

This patch addresses known stale or timing-sensitive checks from the first full Phase 13.4 smoke run.

- `EEE1`: updated the shipped bow loadout expectation to three skills, matching `BowWeaponDefinition.tres` and the later weapon-loadout checks.
- `EEE59`: records `HitEffect.tscn` instances when they enter the Effects container. Hit effects are short-lived, so checking only live instances after the area lifetime could miss effects that spawned correctly and then expired.
- `EEE62`: snapshots the SELF area's center and radius before waiting for its 0.25-second lifetime to expire; the assertion still checks that the nearby goblin was damaged and the caster was not.
- `HHH5`: disables mana regeneration for the test and records mana immediately after activation, so the 20-mana cost is not conflated with regeneration while waiting for the hit.
- `EEE54` and `SSS6`: preserves the assertions and adds diagnostic state to their failure messages to identify which part of the area-spawn or cooldown-wipe contract is failing on the next run.

No runtime smoke test was run while preparing this patch. Re-run the full suite under Godot 4.7.2 and review the new diagnostic values for any remaining failures before treating Phase 13.4 as verified.
