Expected total: 13.3.2's 791 + 13 = **`SUMMARY passes=804 failures=0`**. 13.3.2 is itself still unconfirmed, so if the count is off, first check that 791 held. The step is done only when your run prints 804.

## What changed
- `DashComponent2D.gd`: new `start_skill_dash(direction, speed, duration) -> Vector2`. Starts a dash with the skill's own speed and duration. It is refused (returns `Vector2.ZERO`) while dashing, attacking, casting or stunned, the same states that refuse the normal dash. It neither checks nor starts the character's normal dash cooldown: the skill owns its own cooldown. Movement is still applied only by `MovementComponent2D` through `context.dash_velocity`, and the Idle/Move states already switch to the Dash state when `context.is_dashing` is true, so no state code changed. The direction fallback (given, else movement input, else facing, else right) moved into a private `_resolve_direction()` shared with `try_start()`; `try_start()` behaves as before.
- `SkillDefinition2D.gd`: new `dash_speed` (group Dash, default 700 px/s). A DASH skill's `max_range` is the dash **distance**, so the dash lasts `max_range / dash_speed` seconds (at least 0.05). `validate()` requires `max_range` > 0 and `dash_speed` > 0. The attack is optional: none = a plain dash; with one, its `effect_scene` must be an `AreaEffect2D`.
- `SkillComponent2D.gd`: `_execute_dash()`. It calls `start_skill_dash()` on the caster's dash component, then, when the skill has an attack, spawns the strike through `_execute_area()` (13.3.2) with `follow_time` = the dash duration. A dash that cannot start (no dash component, or something started between cast and execution) warns and does nothing else. `skill_executed` is still emitted, as for every behavior.
- `AreaEffect2D.gd`: `follow_source` (plain variable, set by the skill, not an export). When true the area keeps the offset it had from its source on its first physics frame and moves with it. Default false, so 13.3.2 areas are unchanged.
- `Characters/Components/Skills/LungeSkillDefinition.tres` (new): the shipped dash skill. Lunge, slot 0, no cost, 4 s cooldown, 120 px at 600 px/s (0.2 s), strike of damage 5, knockback 200, hit stun 0.15, a 56 px circle 8 px ahead, `HitEffect.tscn` on impact. **Not on any weapon**: the game plays as before (EEE1 holds). Attaching skills to weapons is 13.5.
- `tests/smoke_checks.gd`: EEE66 to EEE78, constant `LUNGE_PATH`.

## Rules
- The dash starts when the skill **executes** (at once, or when the cast ends). A cancelled cast never dashes and refunds, as in 13.2.
- The skill refuses to start while the caster is already dashing (13.2 gating), so a skill dash and a normal dash never overlap. The normal dash can be used again as soon as the skill dash ends if its own cooldown allows.
- The strike hurts each target once, at any moment of the dash, and never the caster or its team. Knockback goes along the dash direction.
- Walls and bodies stop the caster as for any dash (`move_and_slide`), so a blocked dash covers less than `max_range`; the strike keeps following the caster for the full duration.
- Targeting: AIM_DIRECTION dashes along the given direction or the aim; SELF dashes the way the character is moving, else the way it faces.
- A hit on the caster during the dash does not cancel it (same as the normal dash).

## To use it in the editor
Same as 13.2 / 13.3.1: give the character `ManaComponent2D` and `SkillComponent2D`, add `LungeSkillDefinition.tres` to a weapon's **Skills > Active Skills** (slot 0). A new dash skill is one `.tres`: `behavior` DASH, `max_range` (distance), `dash_speed`, and optionally an `attack` with `AreaEffect2D.tscn` for the strike.
