# Phase 13.4.4 — Mana bar scene

**Implementation status:** implemented in the working archive; Godot smoke test intentionally deferred until Phase 13.4 is complete, per the user's instruction. Runtime behavior has not been verified in Godot yet.

## What changed

- `UI/HUD/ManaBar.tscn` is a reusable, editor-authored scene that follows the existing `HealthBar.tscn` card and layout conventions.
- `UI/HUD/ManaBar.gd` binds through the exported `mana_source` NodePath and observes `ManaComponent2D.mana_changed`. `ManaComponent2D` remains the sole authority for current mana, maximum mana, spending and regeneration.
- The fill uses `UI/HUD/Styles/mana_bar_fill.tres`, a blue `StyleBoxFlat` resource. Panel, background and font styles reuse existing `.tres` assets.
- The scene's `AnimationPlayer` owns `intro`, `spend` and `restore` presentation clips. The numeric counter and progress fill are smoothly tweened by the scene script.
- `Main.tscn` now places `PlayerManaBar` below `PlayerHealthBar`, bound to `../../Player/ManaComponent2D`.
- `tests/smoke_checks.gd` adds checks MMM1–MMM10 for scene placement, source binding, style and animation resources, initial sync, spend/restore feedback, value updates and a missing-source fallback.
